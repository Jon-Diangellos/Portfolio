## Este repositório

Site estático com páginas de apresentação, trajetória e contato:

- `index.html`: apresentação e projetos.
- `sobre.html`: formação e experiência.
- `contato.html`: formulário que abre uma mensagem no WhatsApp para envio pelo visitante.
- `css/style.css`: estilos e adaptação da navegação para telas menores.

### Visualizar localmente

Com Git e Python 3 instalados:

```bash
git clone https://github.com/Jon-Diangellos/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Acesse `http://localhost:8000`. Não é necessário instalar dependências adicionais para servir essas páginas.
